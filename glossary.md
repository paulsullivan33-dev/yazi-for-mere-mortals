# Glossary

**Check:** every term here is used in the
chapters in the sense given; if a chapter
uses one you cannot find, the `~` help
inside Yazi is the next authority.

- **Adapter** — the mechanism `ya env`
  names for turning images into something
  your terminal can show; the fallback
  one is Chafa, which draws in characters.
- **Cwd file** — the file given with
  `--cwd-file`, into which Yazi writes
  its final folder when you quit with
  `q`; the hinge of chapter 11's shell
  trick.
- **Flavour** — a ready-made colour
  scheme for Yazi, installed with
  `ya pkg` and chosen in `theme.toml`.
- **Hidden file** — a file whose name
  begins with a dot; not listed until you
  toggle (`.`) or configure otherwise.
- **Hovered** — the entry in the middle
  pane drawn highlighted; the one your
  keys act on.
- **ioctl** — the operating system's
  mechanism for asking a device questions;
  Yazi's word for why it needs a terminal
  before it will even print help.
- **Linemode** — the `yazi.toml` setting
  choosing what extra fact each listed
  row wears: a size, a count, a date,
  and so on.
- **Nerd Font** — a font patched with
  extra symbols, including the file-type
  icons in Yazi's listings.
- **Opener** — the rule that hands a file
  to a program when you open it: text to
  your editor, and so on.
- **Package** — a plugin or flavour as
  `ya pkg` tracks it: a repository, an
  exact revision, a hash, all recorded in
  `package.toml`.
- **Pane** — one of the three columns of
  Yazi's screen: parent, current,
  preview.
- **Prefix key** — a key that does not
  act alone but opens a menu of what the
  next key can mean: `g`, `t`.
- **Presets** — Yazi's built-in settings
  and keybindings, used when no
  configuration file exists — or when
  yours fails to parse.
- **Previewer** — the component that
  turns the hovered file into what the
  right-hand pane shows.
- **Pseudo-terminal (PTY)** — a software
  terminal the operating system offers a
  program when no physical one exists;
  the lab's robot typed through one.
- **Trash** — the desktop's holding area
  for deleted files (`~/.local/share/
  Trash` on Linux), where `d` puts things
  and from which they can be recovered.
- **Which-key menu** — the little menu a
  prefix key opens, listing the next
  keys and what they do.
- **`ya`** — Yazi's companion program:
  package manager, environment reporter,
  and messenger to running instances.
- **Yank** — Yazi's (and Vim's) word for
  copy: `y` yanks, `p` pastes.
