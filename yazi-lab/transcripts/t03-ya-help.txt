$ ya --help
Yazi command-line interface

Usage: ya <COMMAND>

Commands:
  emit     Emit an action to be executed by the current instance
  emit-to  Emit an action to be executed by the specified instance
  exec     Execute an action on the current instance and print its result
  pkg      Manage packages
  pub      Publish a message to the current instance
  pub-to   Publish a message to the specified instance
  sub      Subscribe to messages from all remote instances
  cache    Manage the cache
  env      Print environment and configuration information
  help     Print this message or the help of the given subcommand(s)

Options:
  -V, --version  Print version
  -h, --help     Print help
