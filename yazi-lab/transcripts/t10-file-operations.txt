Session: opening, renaming, moving, trashing, copying
Start directory: a fresh folder holding archive/ (an empty
folder), draft-letter.txt, measurements.csv and old-notes.txt.
EDITOR and VISUAL were pointed at a three-line script that does
nothing but append its arguments to a log file, so "opening" a
file leaves evidence instead of starting a real editor.

How these screens were captured: the lab has no interactive
terminal, so Yazi ran on a pseudo-terminal (110x32) driven by a
small Python harness (ptyrun.py, kept in this folder). The harness
sent real keystrokes and rendered the terminal with the pyte
library. What you see is the rendered screen, trimmed vertically
where marked [...]. File results were then checked on disk with
ordinary shell commands, which are shown after each session.
The icons in the listings are Yazi's file-type glyphs, drawn from
a Nerd Font; in a plain font they show as boxes or blanks.

Addendum, two more keys from two short sessions:

- Shift-D asks a different question - "Permanently delete 1
  selected file?" - and means it. old-notes.txt was removed
  with D in a fresh copy of the folder, and afterwards the
  trash directory did not exist at all: nothing went there.
- In the playground folder, pressing . (full stop) toggles
  hidden files for the session: .hidden-note.txt appeared in
  the listing at once, with no configuration involved.
- The create prompt makes folders too: typing "new-folder/"
  (with the trailing slash) and Enter produced a folder of
  that name, confirmed both on screen and by ls.
